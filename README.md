# Jummah Bayan App

A modern, mobile-friendly web application for displaying Jummah bayan topics in a clean, infographic-style list layout.

## Features

- 🕌 Clean Islamic design with appropriate color palette
- 📱 Mobile-first, responsive layout
- 🎨 Infographic-style list with numbered badges
- 📖 Full bayan detail pages
- 📦 AdMob-ready placeholder sections
- 🔄 Service Worker for offline caching
- 📲 PWA support for app-like experience
- 🌐 WebView-friendly for Android app conversion
